# クイズメーカー

参考書や資料を読み込んで、自分の過去問・クイズが作れる学習アプリです。ジャンルは問いません。国家試験や資格試験の勉強を想定して作りました。

公開ページ：https://marin0610.github.io/quiz-maker/

## できること

- **教材セット管理**：内蔵のIT教材（基礎用語26問・オリジナルサンプル問題8問）ですぐに始められます。自分の資料を追加して教材セットを増やすこともできます。
- **勉強モード**：フラッシュカード形式で用語・問題と答え・解説を確認。「覚えた」チェックで進み具合が分かります。一覧表示もできます。
- **テストモード**：1問ずつ出題し、答えたその場で正解・不正解と解説が表示されます。
- **試験モード**：本番形式。全部の問題に答えてから提出し、最後にまとめて答え合わせをします。問題番号ドットから見直し・移動ができます。
- **復習モード**：テスト・試験で間違えた問題だけがたまり、正解するとリストから外れます。全教材まとめての復習もできます。
- **結果の履歴**：終わったテスト・試験・復習は、日時・教材・モード・正解率がホームの「結果の履歴」に残ります（最新50件）。
- テスト・復習モードでも「前の問題」に戻れます。答えた問題の解答は変えられませんが、解説を読み直せます。

## 資料の読み込み

- テキストの貼り付け、テキストファイル（.txt / .md / .csv）、PDFファイルに対応しています。
- PDFは文字データの抽出（pdf.js）で読みます。スキャン画像だけのPDFは対象外です。
- 読み込める形式：
  - 用語集：「用語：説明」を1行に1つ（区切りは `：` `:` `=` `|` など）
  - 過去問：`Q.` の問題文、`ア.〜エ.` の選択肢、`A.` の正解、`解説：` の解説という並び。選択肢がない過去問は、他の問題の答えから自動で選択肢を作ります。
- 用語集からは「用語→説明」「説明→用語」の両方向の4択を自動生成します。

## 記録について

- 教材・「覚えた」・間違えた問題・ベストスコアは、すべてブラウザの localStorage に保存され、外部に送信されません。
